# Service Desk Simulator — 30 Tickets Resolved

30 simulated support tickets worked end-to-end: intake, troubleshooting, documentation, resolution, and knowing when to escalate. Built to practice exactly what Tier 1 does all day.

## Ticket categories

| Category | What I practiced |
|---|---|
| Account / access management | Password resets, unlocks, MFA issues, new-hire access |
| Network / connectivity | "Can't reach the internet," VPN, Wi-Fi, IP conflicts |
| Hardware / peripherals | Non-booting PCs, monitors, keyboards, docking stations |
| Printers | Offline printers, driver issues, stuck queues |
| Mobile | Email setup, MDM enrollment, device lockouts |
| Security incidents | Phishing reports, suspicious logins — triage and escalate |

## How I worked each ticket

1. **Intake** — read the user's report, confirmed scope and urgency
2. **Troubleshoot** — reproduced where possible, checked the obvious layers first (physical → network → account → application)
3. **Document** — wrote up symptoms, steps taken, and the fix as if it were going into a real ticketing system
4. **Resolve or escalate** — closed what Tier 1 owns; escalated with full context when it needed Tier 2 or security

## What it drilled into me

- Asking the right clarifying questions before touching anything
- Not skipping layers — half of "complex" tickets are cables, Wi-Fi switches, or expired passwords
- Writing tickets so the next tech (or future me) can pick them up cold
- Escalation isn't failure — it's the job done right when something's above your access level
